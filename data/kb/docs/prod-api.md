# API Reference Overview

## Purpose
This document sets the rules described below. It applies to all employees, contractors, and production systems.

## Api
Corvane Insight provides a REST API documented with OpenAPI 3.1, authenticated with scoped API keys or OAuth 2.0 client credentials.

## Api rate limits
The API allows 600 requests per minute per workspace on the Business plan and 3,000 requests per minute on the Enterprise plan.

## Ownership and review
The owner of this document is the security-lead. It is reviewed at least once a year and after any major change to the platform.
